# Publishing Fiorella's Vision with GitHub Pages

This version is configured for:

`https://fifi702.github.io/fiorellas-vision-portfolio/`

## Publish

1. On GitHub, open **Settings → Pages** for the repository.
2. Under **Build and deployment**, choose **GitHub Actions** as the source.
3. Commit and push this project to the repository's `main` branch.
4. Open the **Actions** tab and wait for **Deploy portfolio to GitHub Pages** to finish.

## Work locally

Run:

```bash
npm install
npm run dev
```

Then open:

`http://localhost:3000/fiorellas-vision-portfolio/`
